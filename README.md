# AI-Based Hybrid Hiring System

## Overview
A hybrid recruitment pipeline that combines:

- ATS keyword matching
- Semantic embeddings
- Rule-based candidate scoring
- Automated candidate reasoning generation

The system processes large-scale candidate profiles and ranks applicants based on skills, experience, career history, recruiter signals, and semantic relevance to the job description.

## Features

- Processes 100,000+ candidate profiles
- AI skill weighted scoring
- Semantic similarity using embeddings
- Career history analysis
- Recruiter signal analysis
- Candidate ranking
- Human-readable reasoning generation

## Tech Stack

- Python
- NLP
- Sentence Transformers
- Semantic Embeddings
- JSON
- Rule-Based Scoring
